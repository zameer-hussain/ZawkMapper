# ZawkMapper Docs

ZawkMapper docs are split into public user documentation and private owner release notes.

## Public docs

Use `docs/public/` for content that can be shared publicly with developers, GitHub, NuGet users, and sample projects.

Recommended public docs:

1. `docs/public/0.6.1-notes.md`
2. `docs/public/performance.md`
3. `docs/public/getting-started.md`
4. `docs/public/projection.md`
5. `docs/public/runtime-vs-projection.md`
6. `docs/public/strict-mapping.md`
7. `docs/public/direct-mapping.md`
8. `docs/public/nested-mapping.md`

## Private docs

Use `docs/private/` for owner-only commands, publishing workflow, release checklist, and internal guidance.

Do not publish API keys, owner-only workflow details, or local machine paths.
